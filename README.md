# Joshua J. Nduwamungu

Source for [joshijo77.github.io](https://joshijo77.github.io/), the personal website of Joshua J. Nduwamungu, Technical Program Manager at Google.

The site is static HTML and one CSS file, with self-hosted fonts and no build step. It is served by GitHub Pages.

## Pages

- [Home](https://joshijo77.github.io/): career highlights, research, publications, journey, and education
- [Research](https://joshijo77.github.io/research/): plain-language summaries of three published papers
- [llms.txt](https://joshijo77.github.io/llms.txt) and [llms-full.txt](https://joshijo77.github.io/llms-full.txt): summaries for AI agents
